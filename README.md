# 홍씨네 캘린더

엄마 근무(휴무·데이·나이트·비번)와 지민·민지·순택 일정을 한눈에 보는 모바일 가족 캘린더.

👉 https://hong-minji.github.io/hongs/

## 일정 수정하기

`schedule.js` 파일만 고치면 됩니다. GitHub에서 파일을 열고 ✏️ → 수정 → **Commit changes** 하면 1~2분 뒤 사이트에 반영돼요.

- **엄마 근무**: `MOM.anchor`(쉬는 날 하나)부터 `MOM.cycle` 순서가 반복됩니다.
- **하루 일정**: `EVENTS`에 한 줄 추가
- **기간 일정**: `STAYS`에 한 줄 추가

## 휴대폰 홈 화면에 추가
- 아이폰: Safari로 열고 공유 → **홈 화면에 추가**
- 안드로이드: Chrome 메뉴 → **홈 화면에 추가**
